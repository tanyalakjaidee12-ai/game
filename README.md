# แตะให้ได้ ถ้าไม่อยากโดนหลอก

เกมแตะจับผีธีมฮาโลวีนสำหรับมือถือ เล่นผ่าน browser ได้ทันทีโดยไม่ต้องติดตั้งแอป

แตะผีให้ทันก่อนมันมุดหนี มีเวลา 60 วินาทีกับ 3 ชีวิต ยิ่งเล่นผียิ่งโผล่เร็ว และระวังแมวดำ มันมาหลอก!

รายละเอียดกติกาทั้งหมดอยู่ใน [REQUIREMENTS.md](REQUIREMENTS.md)

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `src/game.html` | **ตัวเกมจริง** ทั้งภาพ เสียง และกติกาอยู่ในไฟล์นี้ไฟล์เดียว แก้เกมให้แก้ที่ไฟล์นี้ |
| `public/index.html` | ไฟล์ที่เอาขึ้นเว็บ (Vercel) สร้างอัตโนมัติจาก `src/game.html` ห้ามแก้ตรงๆ |
| `scripts/build.mjs` | สคริปต์ที่สร้าง `public/index.html` |
| `REQUIREMENTS.md` | สรุป requirement ของเกม |

## ลองเล่นบนเครื่องตัวเอง

ต้องมี [Node.js](https://nodejs.org) ก่อน แล้วรันคำสั่งในโฟลเดอร์นี้:

```bash
npm run build   # สร้าง public/index.html จาก src/game.html
npm start       # เปิดเซิร์ฟเวอร์ แล้วเข้า http://localhost:3000 ใน browser
```

หรือดับเบิลคลิกเปิด `public/index.html` ใน browser ได้เลย

## ปรับความยากหรือคะแนน

ค่าทั้งหมดอยู่ด้านบนสุดของส่วน `<script>` ใน `src/game.html`:

- `ROUND_MS` เวลาต่อรอบ (มิลลิวินาที, 60000 = 60 วินาที)
- `LIVES` จำนวนชีวิต
- `LEVELS` ความเร็วของแต่ละระดับ (`stay` = ผีอยู่บนจอนานแค่ไหน, `gap` = เว้นระยะก่อนตัวถัดไปโผล่, `max` = โผล่พร้อมกันสูงสุด, `cat` = โอกาสเจอแมว)
- `KINDS` คะแนนและความถี่ของตัวละครแต่ละแบบ

แก้แล้วรัน `npm run build` ทุกครั้งก่อนเอาขึ้นเว็บ
